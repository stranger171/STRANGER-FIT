# Stranger Fit

## AI-Powered Adaptive Training Intelligence System

Stranger Fit is an AI-powered personal training platform designed to track a user's workout history, analyze performance and recovery data, and intelligently recommend the next best workout.

Unlike a basic workout generator, Stranger Fit aims to continuously understand the user's training journey through:

- Workout history
- Exercise performance
- Progressive overload
- Training volume
- Recovery and readiness
- Training consistency
- Personal goals

## Core Vision

Track → Understand → Detect → Decide → Adapt → Explain → Remember

## Version 1 Goal

Build the core training intelligence system that can store workout data, analyze user performance, and generate personalized workout recommendations.

## The Problem

Most workout applications provide static plans or generic recommendations. They do not continuously use a user's actual training history, performance, consistency, and feedback to adapt future workouts.

Stranger Fit aims to solve this by building a training intelligence system that analyzes what a user has actually done and recommends what they should do next.

## Target User

Stranger Fit V1 is designed for gym users who:

- Want to track progressive overload
- Want personalized workout recommendations
- Want to understand their training progress
- Train consistently and record their workouts
- Want an adaptive training system instead of a fixed workout plan

## V1 Features

### 1. User Profile
- Name
- Age
- Height
- Weight
- Fitness goal
- Experience level
- Available training days
- Available equipment

### 2. Exercise Management
- Exercise name
- Primary muscle group
- Secondary muscle group
- Equipment
- Exercise category

### 3. Workout Logging
- Workout date
- Exercise
- Sets
- Repetitions
- Weight
- RPE

### 4. Training Analytics
- Training volume
- Exercise history
- Weekly muscle-group volume
- Progress tracking
- Training consistency

### 5. Adaptive Training Engine
The system analyzes previous workout data and recommends the next best workout using defined training rules.

### 6. AI Explanation
The user can ask why a workout recommendation was made, and the system explains the recommendation using the user's actual training data.
